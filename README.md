# Expense Tracker Application

## About the Project

The Expense Tracker is a web-based application developed using Java and Spring Boot. It helps users record, manage, and track their daily expenses through a simple interface.

## Features

* Add new expenses
* View expense history
* Edit and update existing expenses
* Delete expenses
* View the total of recorded expenses

## Technologies Used

* **Programming Language:** Java
* **Backend Framework:** Spring Boot
* **Frontend:** HTML, Thymeleaf
* **Database:** H2 Database
* **Build Tool:** Maven
* **Version Control:** Git and GitHub

## How to Run the Project

1. Clone or download this repository.
2. Open the project in IntelliJ IDEA.
3. Make sure Java and Maven are configured.
4. Run the `ExpensetrackerApplication.java` class.
5. Open your browser and visit `http://localhost:8080/`.
